JavaScript Scope & Hoisting

1. Scope

Scope: Scope defines where a variable can be accessed in JavaScript.

Example 1: Global Scope

let city = "Hyderabad";

function showCity() {
    console.log(city);
}

showCity();
console.log(city);

Example 2: Function Scope

function test() {
    var message = "Hello JavaScript";
    console.log(message);
}

test();
console.log(message);

Example 3: Block Scope

if (true) {
    let age = 22;
    console.log(age);
}

console.log(age);

Example 4: var vs let

if (true) {
    var course = "JavaScript";
    let duration = "3 Months";
}

console.log(course);
console.log(duration);

2. Hoisting

Hoisting: JavaScript processes declarations before executing the code.

Example 1: var Hoisting

console.log(number);

var number = 100;

console.log(number);

Example 2: let Hoisting

console.log(name);

let name = "Devadasu";

Example 3: Function Hoisting

welcome();

function welcome() {
    console.log("Welcome!");
}

Example 4: Function Expression

hello();

var hello = function () {
    console.log("Hello!");
};
